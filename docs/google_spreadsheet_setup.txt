========================================================================
麻雀成績管理アプリ：Googleスプレッドシート作成手順書
========================================================================

本手順書は、麻雀成績管理アプリのバックエンド（データベース）となる
Googleスプレッドシートを新規作成するための手順書です。
別のパソコン上で以下の手順に沿って設定してください。


------------------------------------------------------------------------
1. スプレッドシートの新規作成と基本設定
------------------------------------------------------------------------
(1) Googleドライブ（https://drive.google.com/）を開き、
    「＋ 新規」＞「Google スプレッドシート」＞「空白のスプレッドシート」
    をクリックして新規作成します。

(2) 左上のファイル名を分かりやすい名前に変更します。
    例：麻雀成績管理_DB（または 麻雀成績管理テンプレート）

(3) メニューの「ファイル」＞「設定」を開き、以下を確認・設定して保存します。
    ・地域：日本
    ・タイムゾーン：(GMT+09:00) 日本標準時 - 東京
    ※日付処理の1日ずれを防ぐため、タイムゾーン設定を必ず確認してください。


------------------------------------------------------------------------
2. シート（タブ）の作成（計4シート）
------------------------------------------------------------------------
画面下部のシートタブを、以下の4つ（大文字・小文字を正確に一致）に
設定します。初期状態の「シート1」の名前を変更し、残り3つを追加してください。

  1) Players
  2) DailyRecords
  3) GameDetails
  4) Settings

※シート名に前後の空白や全角文字が混入しないようご注意ください。


------------------------------------------------------------------------
3. 各シートの1行目（ヘッダー行）の設定
------------------------------------------------------------------------
各シートの1行目（A1セルから横方向）に、以下の見出しを正確に入力します。
※列順・綴り（小文字のスネークケース）を必ず一致させてください。
※下の「タブ区切りテキスト」をそのままコピーし、各シートの A1 セルを
  選択して貼り付けると、各列へ一度に入力できます。

■ 3-1.「Players」シート（A1〜D1：4列）
  A1: player_id
  B1: name
  C1: is_active
  D1: created_at

  【A1に貼り付け用（タブ区切り）】
player_id	name	is_active	created_at

  【推奨書式設定】
  ・A列（player_id）、B列（name）、D列（created_at）を選択し、
    メニュー「表示形式」＞「数字」＞「書式なしテキスト」に設定してください。


■ 3-2.「DailyRecords」シート（A1〜I1：9列）
  A1: session_id
  B1: date
  C1: player_id
  D1: player_name
  E1: game_count
  F1: chip_diff
  G1: chip_point
  H1: total_point
  I1: rule_snapshot

  【A1に貼り付け用（タブ区切り）】
session_id	date	player_id	player_name	game_count	chip_diff	chip_point	total_point	rule_snapshot

  【推奨書式設定】
  ・B列（date）および I列（rule_snapshot）を選択し、
    メニュー「表示形式」＞「数字」＞「書式なしテキスト」に設定してください。
    （日付セルの自動変換・タイムゾーンずれ防止のため重要です）


■ 3-3.「GameDetails」シート（A1〜L1：12列）
  A1: session_id
  B1: date
  C1: game_number
  D1: player_id
  E1: player_name
  F1: wind
  G1: raw_score
  H1: rank
  I1: is_tobi
  J1: tobi_count
  K1: is_yakitori
  L1: final_point

  【A1に貼り付け用（タブ区切り）】
session_id	date	game_number	player_id	player_name	wind	raw_score	rank	is_tobi	tobi_count	is_yakitori	final_point

  【推奨書式設定】
  ・B列（date）を選択し、
    メニュー「表示形式」＞「数字」＞「書式なしテキスト」に設定してください。


■ 3-4.「Settings」シート（A1〜C1：3列）
  A1: setting_key
  B1: setting_value
  C1: updated_at

  【A1に貼り付け用（タブ区切り）】
setting_key	setting_value	updated_at

  【重要：事前書式設定】
  初期値12行を入力する「前」に、必ず B列（setting_value）および
  C列（updated_at）全体を選択し、
  メニュー「表示形式」＞「数字」＞「書式なしテキスト」に設定してください。
  ※この設定を先に行わないと、「10-20」が日付（10月20日）に自動変換され、
    設定値が壊れる原因になります。


------------------------------------------------------------------------
4.「Settings」シートの初期値12行の入力（2行目〜13行目）
------------------------------------------------------------------------
「Settings」シートの B列・C列を「書式なしテキスト」にした状態で、
A2セルを選択し、以下の12行（タブ区切り）をそのままコピー＆ペーストしてください。
（updated_at は任意の作成日時文字列で構いません）

  【A2に貼り付け用（タブ区切り・12行）】
game_type	hanchan	2026/11/23 00:00:00
starting_points	25000	2026/11/23 00:00:00
return_points	30000	2026/11/23 00:00:00
uma_pattern	10-20	2026/11/23 00:00:00
use_tobi	true	2026/11/23 00:00:00
tobi_busted_point	-5	2026/11/23 00:00:00
tobi_flyer_point	5	2026/11/23 00:00:00
use_yakitori	true	2026/11/23 00:00:00
use_chip	true	2026/11/23 00:00:00
chip_rate	2	2026/11/23 00:00:00
use_settlement	true	2026/11/23 00:00:00
settlement_rate	50	2026/11/23 00:00:00

【参考：各設定キーの仕様と設定可能な値】
  1) game_type          : hanchan（半荘） / tonpuu（東風）
  2) starting_points    : 25000 / 30000
  3) return_points      : 25000 / 30000 / 35000
                          ※組合せは以下4パターンのみ有効
                            25000-30000 / 25000-25000 /
                            30000-30000 / 30000-35000
  4) uma_pattern        : 0-0 / 5-15 / 10-20 / 10-30
  5) use_tobi           : true / false
  6) tobi_busted_point  : -1以下の負の整数（初期値: -5）
  7) tobi_flyer_point   : 1以上の正の整数（初期値: 5）
  8) use_yakitori       : true / false
  9) use_chip           : true / false
 10) chip_rate          : 1以上の正の整数（初期値: 2）
 11) use_settlement     : true / false
 12) settlement_rate    : 1以上の正の整数（初期値: 50）


------------------------------------------------------------------------
5. 作成後の最終チェックリスト
------------------------------------------------------------------------
[ ] シートタブが「Players」「DailyRecords」「GameDetails」「Settings」
    の4つだけになっていること（不要な「シート1」等は削除済み）。
[ ] 各シート1行目の列名が、文字数・スペル・小文字まで完全に一致していること。
[ ] 「Players」「DailyRecords」「GameDetails」の2行目以降は空であること。
[ ] 「Settings」の2〜13行目に12個のキーが漏れなく入っていること。
[ ] 「Settings」の B5セル（uma_pattern の値）が日付表示にならず、
    文字列「10-20」のまま表示されていること。
[ ] 「Settings」の B6〜B13 などが左寄せ（テキスト扱い）または正確な値で
    保持されていること（特に「-5」「true」等が意図せず変換されていないこと）。


------------------------------------------------------------------------
6. 次のステップ（GAS設定・テンプレート配布について）
------------------------------------------------------------------------
スプレッドシートの作成が完了したら、同じスプレッドシートのメニュー
「拡張機能」＞「Apps Script」からバックエンド用GASコードを貼り付け、
「デプロイ」＞「新しいデプロイ」＞「ウェブアプリ」として公開します。

※他のメンバーに同じ構成のテンプレートとして配布する場合は、
  GASコードの保存・動作確認後に、スプレッドシートの共有設定を
  「リンクを知っている全員（閲覧者）」にし、URL末尾の「/edit...」を
  「/copy」に書き換えたリンクを配布してください。
