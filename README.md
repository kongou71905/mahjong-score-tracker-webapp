# 目的
GitHubでのWebアプリ作成のお試しとして作成したリポジトリ。<br>
自分用の麻雀成績管理アプリを作成する。

# 特徴
- 1試合ごとの結果入力、1日の試合結果と総合成績表示、過去の成績の一覧表示が可能。
- 対局者ごとに持ち点と席順を入力することで、同点時の上家優先も自動計算する。
- オカ、ウマなどのルールは変更可能とする。
